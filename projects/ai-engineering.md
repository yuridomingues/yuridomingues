# AI Engineering Harness

**Reusable infrastructure for agent-first software engineering.**

This project explores how to make coding agents operate inside software repositories with clearer contracts, isolation and verifiable completion criteria.

## Problem

Agent performance depends on more than the model. Long-running engineering work also depends on orchestration, execution environments, verification and the quality of the repository itself.

## What I built

- task graphs for dependency-aware work;
- isolated worktree workflows;
- planner, builder, verifier and reviewer roles;
- structured handoff contracts;
- runtime verification playbooks;
- adversarial review patterns;
- repository readiness and architecture checks;
- reusable templates for features, bug fixes, refactors and performance work.

## Engineering focus

**AI Engineering · agents · orchestration · evals · verification · MCP · software architecture**

The guiding principle is simple: **done needs executable evidence**.

Instead of solving repeated failures with larger prompts, the project prioritizes tests, schemas, linters, tooling and durable repository guardrails.

## Status

Active personal R&D. The implementation repository remains private while the harness changes quickly; this case study documents the architecture and engineering approach.
