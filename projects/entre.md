# ENTRE

**A collection of short interactive web experiences about perception, nature, music, conversation and time.**

ENTRE is a creative-technology project built around the idea that interaction can explain or provoke an idea better than a static page.

## Experiences

Examples include:

- a tree observed across centuries;
- visual perception experiments;
- a song that can be decomposed into layers;
- branching conversations;
- a life represented as weeks.

## Engineering focus

**Interactive web · frontend engineering · product design · creative coding**

The project is deliberately different from my infrastructure and AI work. It is where I explore autonomy, curiosity and human experience through software.

## Status

Ongoing personal project. The implementation repository is private while the collection continues to change.
